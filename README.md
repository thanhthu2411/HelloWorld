# Hello World Program

This project is a simple Python program that asks user for their name and prints a greeting. If no name is entered, it prints "Hello World".

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Python 3 on your computer
2. Save the code to a file name hello.py
3. Open a terminal in the folder containing the file.

Instructions for using the software:

1. Change the directory path in the terminal to the folder containing the file using: cd folder_name
2. Run the command: python hello.py

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Python 3.x
* A text editor or IDE
